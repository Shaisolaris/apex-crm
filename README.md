# Apex CRM

Sales CRM dashboard with pipeline kanban, deals table, and team metrics.

**[Live Demo](https://shaisolaris.github.io/apex-crm/)**

## Features

- Drag-and-drop pipeline kanban across deal stages
- Sortable deals table with owner, value, and stage
- KPI header with revenue, win rate, and cycle metrics
- Contact and activity panels

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Tech
